# PBI 501.004: Mount the raw modules as their own surface

**Priority:** P3
**Dependencies:** PBI 002.003

## Description

The GitHub, Dropbox and Actions modules are internal libraries in v1, structured so any can be mounted as its own MCP surface. When something other than wagc needs raw file or repo access from CV, mount them as a separate, separately gated surface under the same server, subject to the same audit log and permission boundary.

Traces to Architecture decision 11 and PRD out-of-scope.

## Deliverables

- A second MCP surface exposing the raw module operations, gated by its own secret and permission set.
- Every raw call audited by the same writer as wag calls.

## Acceptance Criteria

- [ ] From CV with the raw surface connected, a file in Dropbox can be listed, read, written and deleted, and each call appears in the audit log.
- [ ] The wag surface's tool list is unchanged by mounting the raw surface.

## Testing Requirements

- [ ] Integration tests per raw operation with audit verification.
