# PBI 501.001: Package wag as a Claude Code plugin

**Priority:** P3
**Dependencies:** PBI 002.003

## Description

Replace the pinned claude-home checkout in runs with a wag plugin installed by name and version from a marketplace, carrying the commands, agents, skills, hooks and MCP servers. Same pin, better package: reproducible per project, upstream-fixable, and no clone-and-build in every run. Deferred until v1 is proven; the project side does not change when this lands.

Traces to Architecture decision 5 and RESEARCH "toolkit pinned, not copied".

## Deliverables

- A wag plugin published from claude-home with the toolkit's commands, agents, workflows, templates and MCP servers.
- The template repo's workflow installs the plugin by name and version instead of checking out claude-home.
- Bumping a project to a newer wag is a one-line change in the project repo.

## Acceptance Criteria

- [ ] A dev run on a project using the plugin completes to a PR with no claude-home checkout in the job.
- [ ] Two projects pinned to different plugin versions each run their own version.

## Testing Requirements

- [ ] An end-to-end run per pinned version.
