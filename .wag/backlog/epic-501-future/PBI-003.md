# PBI 501.003: Move kwiki to a git repo

**Priority:** P3
**Dependencies:** PBI 002.003

## Description

Kwiki stays in Dropbox in v1, edited through the Dropbox module. If Dropbox becomes a liability or the Obsidian read-side moves, kwiki becomes a git repo edited through the GitHub module, with Dropbox at most a synced mirror. Deferred; reopen only on that condition.

Traces to RESEARCH rejected alternatives.

## Deliverables

- Kwiki as a git repo with its raw, wiki, index and log intact.
- The server's dig-phase writes to kwiki go through the GitHub module.
- A mirror to Dropbox for Obsidian, if still wanted.

## Acceptance Criteria

- [ ] A kwiki ingest from CV lands as a commit.
- [ ] Obsidian on the iPad still reads every page.

## Testing Requirements

- [ ] One ingest and one query end to end after the move.
