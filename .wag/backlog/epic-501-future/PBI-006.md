# PBI 501.006: Scaffold an app baseline at init

**Priority:** P3
**Dependencies:** PBI 002.003

## Description

Wag2's init stands up a baseline app before the backlog so every PBI is a vertical slice on a running project. wagc's v1 init (PBI 001.008) produces the planning layer and the workflow only, and the first PBI's dev run stands up the app. This slice adds the scaffold to init as a run: approve init dispatches a scaffold job that runs the chosen scaffolder in the new repo and commits the baseline, so the backlog is authored against a booting app as wag2 intends.

Traces to the wag2 init workflow Phase C.

## Deliverables

- Approve init dispatches a scaffold run after the repo is generated, choosing the scaffolder from the Architecture draft's baseline.
- The run commits a booting baseline on dev and orient reports it before offering the first PBI.

## Acceptance Criteria

- [ ] Init on a Next.js project results in a repo whose dev branch boots the baseline app before any PBI is picked.

## Testing Requirements

- [ ] One end-to-end init with scaffold on a throwaway project.
