# PBI 501.005: Decision captures returned on orient

**Priority:** P3
**Dependencies:** PBI 002.003

## Description

During discovery many paths are considered and rejected, and a later CV session has no memory of them. This slice would let save carry structured decision captures (chosen, rejected, why, reopen-if) and have orient return the path so far, so a rejected shape is not re-proposed. Dropped in discovery on 2026-09-04 with "we'll know it if we need it". Reopen when a session re-proposes something already rejected and it costs real time.

Traces to RESEARCH rejected alternatives.

## Deliverables

- Save accepts a structured decision capture as an artifact type, appended to the planet's dated decision doc.
- Orient returns the project's decision captures, summarised when long, alongside the phase and ritual.
- At init approve, the captures become the RESEARCH doc's alternatives section.

## Acceptance Criteria

- [ ] After a decision capture is saved, the next orient in a fresh CV session returns it.
- [ ] Init produces a RESEARCH doc whose alternatives section is derived from the captures.

## Testing Requirements

- [ ] Unit tests for capture shape and summarisation.
- [ ] Integration test across two sessions.
