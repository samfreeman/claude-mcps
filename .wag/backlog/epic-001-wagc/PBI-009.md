# PBI 001.009: Snag and tri

**Priority:** P1
**Dependencies:** PBI 001.003

## Description

The snag continuation and the tri phase. Snag captures a defect in an upstream doc from CV and halts every phase until tri clears it. Orient with an open snag reports tri as the only permitted step and returns the resolution ritual: fix at the source, propagate to docs and backlog, disposition local, global or both. Save records the resolution steps; approve in tri checks the snag is fully resolved, moves it to resolved, and commits; with no snag open, the next orient derives the phase from the artifacts again. Global dispositions land as a stash-style note against claude-home rather than an edit, since the server does not write the toolkit.

Traces to the wag2 halt-on-snag rule and snag-resolution protocol, Architecture decision 6.

## Deliverables

- The snag continuation accepts a snag description (title, target doc and section, what is wrong, why it matters) and writes a numbered snag file using the wag2 snag template into the project repo, recording the phase that was active.
- Orient with any open snag reports tri as the sole next step, lists the open snags, and returns the resolution ritual.
- Save in tri records the fix (edits to the target doc with version bump and changelog), propagation (affected PBIs or the active ADR amended), and the disposition.
- Approve in tri checks: the target doc changed, propagation is recorded, the disposition is stated, and for a global or both disposition the note for claude-home is written. Then moves the snag to resolved and commits; nothing else changes, because the halt was only ever the snag file's presence.
- The cycle-end tri (after merge) drains the latest review's snag candidates and the stash through the same ritual.

## Acceptance Criteria

- [ ] From CV, in any phase, snagging with a description results in a snag file in the repo and the next orient reporting tri only.
- [ ] Approve on any non-tri continuation while a snag is open refuses and directs to tri.
- [ ] Resolving through save and approving tri results in the snag under resolved, the target doc versioned and changelogged, and the next orient deriving the phase from the artifacts again.
- [ ] Approving tri with no change to the target doc refuses and says so.
- [ ] A global disposition produces a note the ritual tells Sam to carry to claude-home; the server writes nothing to claude-home.
- [ ] After a merge, orient offers the cycle-end tri and lists the review's snag candidates and stash items.

## Testing Requirements

- [ ] Unit tests for snag numbering, halt detection and phase derivation after resolution.
- [ ] Unit tests for the tri approve checks.
- [ ] Integration test: snag, resolve, approve on a test repo across two orients.
- [ ] Negative test: approve tri with an unresolved second snag still open.

## Technical Notes

The snag template and resolution protocol are in claude-home under wag templates and workflows; served the same way as other rituals.
